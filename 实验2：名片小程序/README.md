# 实验2：个人名片小程序

## 实验内容

使用AI生成16:9个人名片，制作个人名片微信小程序。

## 实现功能

顶部展示名片，下方展示个人介绍的详细内容；另点击按钮后，淡入显示uid、欢迎语等。

## 优化点

1. **界面**：调整姓名标题字号、加粗、颜色，增加灰色副标题与分割线；头图顶格铺满，信息拆分为多个板块，板块标题蓝色加粗；用圆角标签，部分标签深色高亮。
2. **交互**：点击按钮切换显示状态，按钮隐藏的同时UID区域淡入出现。
3. **数据**：使用布尔变量 `showGenshin` 控制状态，`wx:if` 分别绑定按钮与 UID 区域，点击后 `setData` 修改变量驱动页面自动切换。
