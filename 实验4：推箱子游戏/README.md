# 实验 4：推箱子游戏

## 实验内容

按实验书（周文洁《微信小程序开发实战》第 13 章）要求完成并润色，实现推箱子益智小游戏开发，保留教材核心玩法：8×8 棋盘、方向键移动推箱子、重新开始关卡。

## 实现功能

首页展示关卡选择列表，包含关卡预览、通关进度、最佳记录，点击关卡卡片进入游戏页面；游戏页面展示游戏棋盘，支持方向按键与手势滑动操控主角移动推箱子，实时显示步数、推箱次数、用时；支持撤销回退、重新开始游戏；全部箱子推至目标点后触发通关，自动解锁下一关卡，本地存储保存每一关最佳步数与用时。图片资源加载失败时自动切换矢量图形渲染，避免画面空白。

## 优化点

1. **界面**：废弃教材旧版`canvas‑id`接口，升级为新版`canvas type="2d"`，做设备像素比 DPR 高清适配；采用沉浸式自定义导航栏，规避微信胶囊按钮遮挡；首页关卡卡片展示迷你棋盘预览；游戏页圆角棋盘、摇杆样式方向按键；通关弹窗展示游戏成绩，搭配全屏彩带动画与设备震动反馈；深色渐变主题，卡片圆角美化。
2. **交互**：主角与箱子移动增加平滑过渡动画；主角待机有呼吸起伏，移动实现跳跃拉伸、左右镜像翻转，眼睛跟随移动方向转动；目标点小猪待机呼吸脉动；新增每关开场剧情对话气泡；箱子推到目标位置弹出随机语气气泡；增加音效与背景音乐，遵循平台规则，需要用户手势触发播放；支持一键解锁全部关卡的问答功能，支持游戏内直接唤起选关面板。
3. **数据**：关卡地图、剧情台词统一维护在`utils/data.js`；共 8 个关卡，1‑4 关沿用教材原始地图，新增 5‑8 关自定义关卡，全部关卡经过求解器验证保证可解；使用本地缓存保存关卡解锁状态、最佳记录、音频开关配置；采用双图层存储地图与箱子数据，历史记录数组配合二维数组深拷贝实现撤销功能，通过`setData`与渲染循环驱动画面更新。
