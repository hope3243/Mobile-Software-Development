# 推箱子小游戏（hope004 · 优化版）

基于周文洁《微信小程序开发实战》第十三章「推箱子游戏」实验，在不改变核心玩法
（8×8 棋盘、方向键移动/推箱、重新开始）的基础上，做了现代化改造和功能增强。

## 目录结构

```
hope004
├─ app.js / app.json / app.wxss    全局配置
├─ project.config.json              项目配置（AppID 默认为游客模式，可自行替换）
├─ sitemap.json
├─ utils/
│   └─ data.js                      8 个关卡的地图数据（1~4 来自教材，3 已修正；5~8 新增）
├─ images/                          预留图片目录（当前版本全部矢量绘制，无需图片素材）
└─ pages/
   ├─ index/                        首页：关卡选择、进度展示、迷你预览图
   └─ game/                         游戏页：棋盘、方向键、统计、撤销等
```

## 使用说明

1. 打开微信开发者工具 →「导入项目」→ 选择本 `hope004` 目录。
2. AppID 可使用「测试号」，或把 `project.config.json` 中的 `appid` 换成自己的
   AppID（当前为 `touristappid` 游客模式）。
3. 基础库建议选择 2.20.1 及以上版本（项目已配置 `libVersion: 3.0.0`），
   以使用新版 Canvas 2D 接口。
4. 编译运行即可。

## 与教材相比的改进

### 0. 老师要求的图片素材（boxgame_images.zip）已集成
- 首页：使用老师提供的 level01~04.png 作为第 1~4 关预览图；第 5~8 关用同一套游戏图标自动生成了风格一致的 level05~08.png。
- 游戏页：8×8 棋盘使用老师提供的 icons 图标（ice 地板 / stone 墙 / pig 目标 / box 箱子 / bird 主角）绘制，图标加载失败时自动回退为矢量绘制。

### 1. 技术现代化（修复因开发工具/基础库更新导致的问题）
- 旧版 `<canvas canvas-id>` + `wx.createCanvasContext` 已废弃，改为新版
  `<canvas type="2d">` + `canvas.getContext('2d')`，并按设备像素比（DPR）高清适配。
- 全部画面（地板、墙、箱子、目标点、主角）由代码矢量绘制，不依赖任何图片素材，
  因此不再需要下载教材的图片包，也不会出现素材缺失问题。
- 使用 `wx.getWindowInfo()`（带旧接口降级），导航栏改为沉浸式自定义导航栏。

### 2. 玩法与交互增强
- 移动/推箱平滑动画（主角和箱子滑动过渡，主角朝向移动方向）。
- 步数、推箱次数、用时实时统计；首次移动后开始计时。
- 撤销（↺）按钮：可一步步回退。
- 手势支持：在棋盘上滑动手指即可移动。
- 重新开始：一键复位当前关卡。

### 3. 关卡与进度
- 共 8 关：1~4 关沿用教材数据，其中**第 3 关已修正**（教材原版第 3 关两个上方
  目标点被墙封死，无法通关）；5~8 关为新增关卡。
- 每关均经过求解器验证可解（最短步数依次约为 51 / 10 / 54 / 61 / 17 / 20 / 27 / 33）。
- 通关自动解锁下一关，未解锁关卡在首页和选关面板中锁定显示。
- 每关记录最佳步数/最佳用时，存于本地缓存，通关后自动保存并提示是否刷新纪录。

### 4. 界面美化
- 深色渐变主题 + 圆角卡片 + 背景光斑装饰。
- 首页每个关卡卡片动态绘制迷你棋盘预览图。
- 游戏页：自定义导航栏、统计栏、圆角棋盘、摇杆式方向键。
- 过关庆祝：弹窗展示成绩 + 全屏彩带动画 + 震动反馈。

## 地图数据说明（utils/data.js）

数字含义：0 空地（不绘制）、1 墙、2 地板、3 目标点、4 箱子、5 玩家。
地图中的 `4`（箱子）和 `5`（玩家）在初始化时会拆分为「地形层 map」与
「箱子层 box」两个 8×8 数组进行渲染与逻辑判断。


## 新增花样（hope004.1 增强版）

- **剧情系统**：每关开场小鸟都会弹出剧情气泡（救出小猪的故事线），点击开始游戏后开始。
- **动态小鸟**：移动时小鸟会跳跃拉伸、眼睛看向移动方向（上下左右各不相同），待机时轻微呼吸起伏。
- **动态小猪**：目标点的小猪会原地呼吸脉动，看起来更生动。
- **动态成功界面**：通关后弹出祝贺面板，小鸟站在旁边说恭喜（每关台词不同），步数/推箱/用时数字滚动增长，配合全屏彩带。
- 连续动画渲染循环（Canvas 2D + requestAnimationFrame），旧设备不支持时自动降级为静态绘制。
