# 实验3：高校新闻网（微信小程序）

按实验书（周文洁《微信小程序开发实战》第14章）要求完成，新闻素材已替换为**中国海洋大学 2026 年要闻**。

## 页面与功能
- **首页 pages/index**：swiper 幻灯片（3 张图片自动播放，本地图片）+ 新闻列表，点击标题跳转新闻全文
- **新闻页 pages/detail**：显示标题/图片/正文/日期；「点击收藏 / 已收藏」切换，本地缓存收藏；**未登录时点收藏会提示先去登录**
- **个人中心 pages/my**：默认未登录 → 点“未登录，点此登录”弹出登录面板（**chooseAvatar 选头像 + nickname 输入昵称**，或**微信一键同步**）；登录后展示收藏列表，点击可再次查看

## 登录流程（新版 API，替代已废弃的 open-type="getUserInfo"）
1. 首次进入默认未登录，个人中心只显示“未登录，点此登录”按钮；
2. 点击按钮后出现登录表单：点头像框调用 open-type="chooseAvatar" 选择微信头像，在“请输入昵称”框输入昵称；
3. 点“完成登录”即登录成功；或点“微信一键同步”用 wx.getUserProfile 直接拉取微信头像昵称；
4. 登录状态写入本地缓存（isLogin、userInfo），下次进入自动恢复；
5. 在新闻详情页未登录点“点击收藏”会弹窗提示“收藏前请先登录”，点“去登录”跳到个人中心页。

> 说明：微信从基础库 2.21.2 起不再向开发者返回真实头像昵称，wx.getUserProfile / open-type="getUserInfo" 得到的可能是默认灰色头像和“微信用户”，所以本项目以“chooseAvatar + nickname 输入”为主，微信同步作为辅助。
