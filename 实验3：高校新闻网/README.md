# 实验 3：高校新闻网（微信小程序）

## 实验内容

按实验书（周文洁《微信小程序开发实战》第 14 章）要求完成并润色，实现新闻网小程序开发。

## 实现功能

首页展示 swiper 幻灯片（3 张本地图片自动播放）与新闻列表，点击新闻标题跳转新闻全文页面；新闻详情页展示标题、图片、正文、发布日期，支持收藏切换与本地缓存收藏，未登录点击收藏会提示跳转登录；个人中心页面实现新版登录逻辑，登录后展示收藏列表，点击条目可再次查看新闻。

## 优化点

1. **界面**：首页 swiper 使用本地图片自动播放；新闻列表公共样式统一写在`app.wxss`，首页和个人中心收藏列表共用；详情页海报图片设置 700rpx 宽度规避图片不显示 bug；配置 tabBar 两套图标实现选中 / 未选中状态切换；页面板块拆分清晰，排版整洁。
2. **交互**：点击新闻标题完成页面跳转；收藏按钮切换「点击收藏 / 已收藏」文字状态；未登录点击收藏弹出提示弹窗，点击 “去登录” 直接跳转个人中心；个人中心唤起登录面板，支持 chooseAvatar 选头像 + 输入昵称、微信一键同步两种登录方式；登录状态本地持久化；我的收藏列表点击可重新打开新闻详情。
3. **数据**：使用本地缓存保存登录状态`isLogin`、用户信息`userInfo`、收藏新闻数组；新闻 id 作为收藏唯一标识，读取收藏时过滤非新闻缓存对象，避免数据错乱；条件渲染控制登录面板、登录提示、收藏列表显示隐藏，通过`setData`驱动页面自动更新。
