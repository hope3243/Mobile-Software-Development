# 实验1：热身运动——第一个微信小程序

## 一、实验内容
本次实验为移动软件开发课程入门热身实验，主要学习微信开发者工具的使用，掌握手动创建空白原生小程序的完整流程。通过跟随官方教程编写 Hello World 案例，熟悉 WXML、WXSS、JavaScript 三种文件的分工：WXML 负责页面结构搭建，WXSS 负责页面样式布局，JS 负责数据处理与点击交互。

在完成基础功能后，我对项目进行了完整优化，分别从界面样式、交互逻辑、数据结构三个维度改进代码，使页面更加美观、交互更加流畅、代码更加规范易拓展。

## 二、实验功能实现
实现多状态图文联动切换，点击按钮可在 **girl、boy、cat** 三种状态之间无限循环切换文字与对应图片。

## 三、项目优化内容
### 1. 界面样式优化
调整标题字号、字体加粗、文字配色，设置页面顶部边距，优化图片上下、左右间距，解决原生页面排版拥挤、样式简陋的问题，使整体页面布局整洁协调。

### 2. 交互逻辑优化
优化点击事件，实现文字内容与展示图片同步联动切换，支持多状态无限循环，交互效果更加完整流畅。

### 3. 数据结构优化
摒弃传统冗余的 if-else 多分支判断，采用**对象数组**统一管理所有图文状态。通过取余算法实现循环切换，新增或删减展示状态仅需修改数组数据，无需修改逻辑代码，代码结构清晰、可拓展性强。

## 四、项目结构
- mini-program：小程序完整源码
- images：实验运行截图

## 五、运行方式
使用微信开发者工具导入 mini-program 文件夹，直接编译运行即可。
