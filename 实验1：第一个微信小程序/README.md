# 实验1：热身运动——第一个微信小程序

## 实验内容
学习使用微信开发者工具手动创建小程序，理解WXML、WXSS、JS的分工，完成Hello‑World案例并优化代码（（你喜欢小猫吗？）。

## 实现功能
点击按钮，girl/boy/cat三组图文循环切换。

## 优化点
1. **界面**：调整字号、颜色、加粗，修改边距，优化页面排版。
2. **交互**：实现文字与图片同步联动切换。
3. **数据**：使用对象数组管理状态，便于扩展。

## 项目结构
- hope001：小程序源码
- report001：实验报告

## 运行
微信开发者工具导入hope001文件夹即可。
