# 实验 5：鸿蒙开发入门及计算器开发

## 实验内容

按实验要求完成 DevEco Studio 与 HarmonyOS 开发环境配置，以官方计算器示例为基础，使用 ArkTS 与 ArkUI 开发并润色多功能计算器。保留标准计算器核心功能：数字及小数输入、加减乘除、百分号、清空、退格和等号计算，并在 X View 中完成运行调试。

## 实现功能

计算器支持标准与科学两种模式，点击左上角按钮即可切换。标准模式能够完成基本四则运算并实时预览结果；科学模式增加 `sin`、`cos`、`tan`、`ln`、`log`、平方、立方、任意次幂、平方根、任意次根、阶乘、倒数、括号、常数 `π` 和 `e`，并支持角度制、弧度制与反函数切换。应用提供 `MC`、`M+`、`M-`、`MR` 存储器按键，计算完成后自动保存历史记录，可查看并一键清空全部记录。

右上角三点菜单集中管理扩展功能，包括历史记录、单位换算、日期计算和主题色切换。单位换算支持长度、质量、温度、面积、体积和存储六类单位；日期计算支持计算两个日期相差的天数，以及目标日期距离今天还有或已经过去多少天；主题提供蓝、紫、绿、橙四种配色并保存用户选择。

## 优化点

1. **界面**：采用标准与科学模式分区设计，科学计算按键使用 3 行×6 列单页布局；将历史记录、单位换算、日期计算和主题选择收纳到右上角三点菜单，减少顶部拥挤；统一调整按键尺寸、间距、圆角和淡阴影，等号与运算符随主题色变化；优化显示区与键盘的空间分配，减少科学模式底部空白。
2. **交互**：所有按键增加按压缩放与回弹效果；普通输入时显示闪烁竖线光标，按下等号后结果从下向上弹出；退格键短按逐位删除、长按清空，等号结果可一次删除；输入内容过长时自动缩小字号，达到最小字号后支持水平滚动并自动跟随末尾光标。
3. **功能与数据**：表达式按照运算符优先级计算，支持括号、幂和任意次根，并处理负数奇次根、零次根、阶乘范围和无效结果；历史记录最多保存 30 条；使用持久化存储保存历史记录、存储器数值与主题设置；日期计算按真实日历处理月份天数和闰年，并通过日期序号避免时区导致的天数偏差。
