# 小室友 Roomie

## 项目内容

按假期生活主题完成并优化“小室友 Roomie”微信小程序，将待办、番茄专注、微信步数、心情日记、出行照片和周期回顾集中在一个应用中，并通过可互动柴犬、成长印记和小窝装饰增强陪伴感。项目使用原生微信小程序、TypeScript、Less、Canvas 2D 与微信云开发实现。

## 实现功能

今日页支持事项新建、编辑、完成、删除和提醒，展示当天专注时间、微信步数，并可记录心情与日记；专注页提供自由专注、事项关联、暂停恢复、提前结束及雨声、时钟白噪音；拾光页支持创建出行册、管理出发清单、逐日行程和最多 9 张照片，并可制作三款照片卡；回顾页生成日、周、月统计及回顾海报；小窝页展示成长印记、阶段称呼、装饰和收藏照片卡。首页与小窝中的 Roomie 支持点击、长按和拖动互动。

## 优化点

1. **界面与交互**：采用薄荷青绿、雾白和杏橙配色，统一卡片、圆角、按钮和字体层级；首页与小窝随真实时间切换白天、晨昏和黑夜，雨天显示动态雨滴；专注页增加连续滚动的草地、树木、云朵和飞鸟。Roomie 使用完整柴犬图片绘制，实现呼吸、眨眼、轻跳、庆祝、行走、拖动惯性和松手回位，并根据当天事项、专注和步数给出简短提醒。
2. **记录与统计**：事项时间默认从今天当前时刻开始；出行册分开展示与编辑，行程可自动进入今日待办；照片支持预览、裁切、画框、收藏和保存。长记录采用分批展开，避免页面无限增长；回顾统计事项完成率、专注、步数、心情、日记和照片，并根据数据生成不同评价。
3. **云开发与可靠性**：`roomieWeRun` 通过 CloudID 读取可信微信步数，`roomieWeather` 代理城市天气，`roomieSync` 按 `OPENID` 隔离用户并自动同步记录和照片。数据优先保存在本机，断网不影响记录；保存失败会回滚，重复同步不会重复增加印记。

## 运行

使用微信开发者工具导入项目根目录并填写自己的 AppID；创建云开发环境，将环境 ID 配置到 `miniprogram/config/cloud.ts`；上传并部署 `roomieWeRun`、`roomieWeather` 和 `roomieSync` 云函数，选择云端安装依赖；为 `cloudfunctions` 选择对应环境后重新编译。真机首次读取步数时需要允许微信运动权限，天气功能需在设置中选择一次城市。请勿将 AppSecret 或其他密钥提交到仓库。
