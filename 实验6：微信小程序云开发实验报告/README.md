# 实验 6：微信小程序云开发

## 实验内容

按实验要求完成并润色，实现“拾光 FRAME”生活影像分享小程序，保留图片上传、作品浏览、个人主页等核心功能，结合云存储、云数据库和云函数，完成作品发布与互动流程。

## 实现功能

发现页展示双列作品列表，支持关键词搜索和自然、城市、旅行、日常、人像分类筛选；发布页支持最多 9 张图片上传、图片预览与删除、封面标记、草稿保存，可填写标题、描述、主题和拍摄地点；作品详情页支持图片预览、保存原图、分享、点赞、收藏与评论；收藏页集中展示已收藏作品；个人主页展示头像、昵称、发布数量与收藏数量，支持编辑个人资料、查看和删除自己的作品；点击作者信息可进入作者主页。

## 优化点

1. **界面**：采用米白与墨绿色主题，统一圆角卡片、字体和留白；发现页增加主题横幅、分类导航和双列图片展示；作品卡片显示作者头像、类别及点赞数量；发布页采用三列九宫格，添加图片入口与缩略图保持相同尺寸并连续排列；个人主页采用圆形头像与横向资料布局；悬浮发布按钮保持圆润紧凑，底部导航配置普通与选中状态图标。
2. **交互**：搜索框支持一键清除；首页卡片可直接点赞，详情页分别提供点赞、收藏和评论入口；页面返回时刷新互动状态，避免不同页面显示旧数量；支持删除自己的评论；多图发布显示上传进度，草稿减少重复输入；补充加载、空列表与操作结果提示，并修复中文昵称编码显示、按钮默认样式和文本换行等问题。
3. **数据**：使用云存储保存图片、`photos` 集合保存作品，统一通过 `photoService` 云函数处理发布、查询、删除及互动；利用微信上下文中的 `OPENID` 识别用户，校验作品与评论归属；点赞、收藏和评论使用事务更新，减少并发覆盖；数据库采用仅创建者读写权限，云函数提供受控访问；兼容旧作品缺少互动字段的情况，并提供本地演示数据。

## 项目结构

- hope006：小程序源码，包含前端页面与云函数
- report006：实验报告

## 运行

微信开发者工具导入 hope006 文件夹，填写自己的小程序 AppID，创建云开发环境并在 `miniprogram/config.js` 中配置环境 ID；创建 `photos` 集合，权限设置为“仅创建者可读写”；上传并部署 `cloudfunctions/photoService` 云函数，选择云端安装依赖，编译后即可运行。
