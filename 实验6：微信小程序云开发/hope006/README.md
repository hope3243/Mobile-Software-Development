# 拾光 FRAME · 实验六图片分享社区

在原 hope006 项目中实现，微信原生小程序，无第三方前端依赖。

## 运行
1. 微信开发者工具导入本目录，保留原 AppID，基础库选择 3.17.2 或工具中可用的更高稳定版本。
2. 编译入口为 pages/index/index。未配置云环境时进入带标识的本地体验模式。精选图是 Unsplash 网络示例图，需要联网；加载失败有占位提示。
3. 发现页搜索、分类筛选，点图片进入详情，点作者进入主页。右下角发布按钮可发布 1–9 张图片。
4. 个人页可主动填写昵称和选择头像。文字草稿保存在本机，恢复草稿后需重新选图。收藏也保存在本机。

## 启用真实云开发（实验验收前必须完成）
1. 在微信开发者工具开通/选择云环境，将环境 ID 填入 miniprogram/config.js 的 env。
2. 创建 photos 集合。设置自定义安全规则为 database.rules.json 的内容（前端禁止直接读写，统一经过云函数）。
3. 对 cloudfunctions/photoService 右键“上传并部署：云端安装依赖”。云函数使用当前环境，并从云上下文获取 OPENID，不能由客户端伪造作者。
4. 配置云存储为所有用户可读、仅创建者可写，允许登录用户上传。重新编译后首页的本地体验提示消失。
5. 分页查询按 createdAt 降序；按控制台索引提示为 category + createdAt、_openid + createdAt 建复合索引。数据库权限与集合须在控制台配置，代码不会自动修改账户。
6. 使用两个微信账号验证发布后互相可见、作者主页筛选、分享详情链接及无法删除他人作品。

## 实验对应关系
- 云函数：photoService/identity 取得 OPENID；publish 校验字段并写入作者身份；remove 验证所有权。
- 云存储：多图上传后将 fileID 存入 photos；原图下载后保存相册。
- 云数据库：按时间分页、主题筛选、标题/描述/作者搜索、作者主页、详情读取。
- 页面：首页、上传页、作者主页、详情页，加收藏页和个人空间。
- 图片交互：九图上限、封面、预览、删除选图、进度、失败重试、收藏、保存当前图片和好友分享。

## 数据说明与限制
本地模式上传使用 wx.saveFile 保存到当前设备，清理缓存后可能失效，不能生成跨设备分享。它不会假装执行云上传。
云端发布通过请求编号实现幂等写入。为避免网络响应丢失时误删已发布图片，失败上传的文件保留在云存储；删除作品移除数据库记录，不立即删除云文件，需在云控制台按引用情况清理孤立文件。
本地模式头像保存在设备；云端模式头像上传云存储并随新作品展示。新发布作品保存当时头像和昵称，历史作品不会自动追溯更新。
示例图来自 images.unsplash.com；需要保存示例网络图时，将 https://images.unsplash.com 配置为 downloadFile 合法域名。云端用户图片使用 wx.cloud.downloadFile。
相册保存、好友分享、隐私授权及云端权限最终以微信真机为准。正式发布前需在小程序管理后台配置涉及选图、头像和相册保存的隐私保护指引，并完成平台要求的审核；当前为课程实验实现。
